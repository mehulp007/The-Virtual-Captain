# The Virtual Captain

Pick a batter, a format and a match situation. See the field a reinforcement-learning captain
sets, compare it with the textbook field and with optimised ones, then move the fielders
yourself and watch what it costs.

Built from 5.85 million deliveries of Test, ODI and T20 cricket, a shot model per batter and a
fielding simulator calibrated against real outcomes. Code, method, results and limitations:
[github.com/mehulp007/The-Virtual-Captain](https://github.com/mehulp007/The-Virtual-Captain).

Ball-by-ball data from [Cricsheet](https://cricsheet.org/); tracking fields derived from
ESPNcricinfo, used for non-commercial purposes only.
